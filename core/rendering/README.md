# Rendering

## Responsibility

### What problem does Rendering solve?

Transforms application state into a visible user interface.

### Why does Rendering exist?

To display data and user interactions on the screen.

### When is Rendering needed?

Whenever the UI is first displayed or updated.

---

## Concepts

### Declarative UI

Describe what the UI should look like for a given state.

### Virtual DOM

An in-memory representation of the real DOM.

### Reconciliation

The process of comparing the old and new Virtual DOM.

### Rendering Pipeline

The sequence of steps from state change to pixels on the screen.

### Browser Rendering

The browser process of layout, paint, and compositing.

### Rendering Lifecycle

The stages a component goes through while rendering.

### Hydration

Attaches JavaScript to server-rendered HTML.
