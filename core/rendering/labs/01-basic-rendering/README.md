# Lab 01 - Basic Rendering

## Objective

Understand how application state is rendered into a user interface.

---

## What I'm Building

A simple application that demonstrates basic rendering.

---

## Concepts Covered

- Declarative UI
- Virtual DOM
- Reconciliation
- Rendering Pipeline

---

## Patterns Used

- Client-Side Rendering (CSR)

---

## Tools Used

- React
- Vite
- React DOM

---

## Success Criteria

- Render UI from state.
- Update the UI when state changes.
- Observe component re-rendering.
- Explain the rendering process.
