# Trade-offs

## CSR vs SSR

CSR offers richer interactivity but slower initial loads.
SSR improves initial load and SEO but increases server work.

---

## SSG vs ISR

SSG is extremely fast but content can become outdated.
ISR keeps content fresh with minimal rebuilds.

---

## Memoization

Improves performance but adds complexity and memory usage.

---

## Virtualization

Improves performance but makes implementation more complex.

---

## Streaming

Improves perceived loading but increases implementation complexity.
